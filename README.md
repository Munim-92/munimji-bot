# 🤖 MunimJi Bot

Personal + Business Expense Tracker Telegram Bot

## Features
- 👤 Personal + 💼 Business mode
- 📱 Mobile + Email signup
- 🎁 30 din free trial
- 💳 UPI payment + Admin approval
- 📊 Reports, Budget alerts, Search

## Deploy on Railway

1. GitHub pe yeh repo upload karo
2. railway.app pe jaao
3. "New Project" → "Deploy from GitHub"
4. Environment variable add karo:
   - `BOT_TOKEN` = aapka telegram token
5. QR code image `qr.jpg` naam se repo mein daalo
6. Deploy!

## Admin Commands
- `/approve USER_ID` — payment approve
- `/reject USER_ID` — payment reject  
- `/stats` — bot statistics
